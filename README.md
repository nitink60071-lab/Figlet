# Figlet - ASCII Text Generator

A simple Node.js project that converts normal text into large and stylish ASCII art using the Figlet package.

## About

This project demonstrates how to use an external npm package in a Node.js application.

The Figlet package takes normal text and converts it into ASCII art that can be displayed directly in the terminal.

## Features

- Converts normal text into ASCII art
- Simple and beginner-friendly Node.js project
- Uses the Figlet npm package
- Runs directly in the terminal

## Technologies Used

- Node.js
- JavaScript
- Figlet

## How to Run

1. Clone the repository:

   git clone https://github.com/nitink60071-lab/Figlet.git

2. Open the project folder:

   cd Figlet

3. Install dependencies:

   npm install

4. Run the project:

   node index.js
